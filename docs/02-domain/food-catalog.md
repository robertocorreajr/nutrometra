# Catálogo de alimentos e medidas

## Objetivo
Fornecer base estruturada para montagem de dietas por refeição, com foco em clareza para o profissional e compreensão simples para o paciente.

## Requisitos do catálogo
- alimentos globais do sistema;
- alimentos customizados por tenant;
- aliases/sinônimos;
- categoria e subcategoria;
- unidade padrão;
- medidas caseiras;
- observações de preparo;
- nutrientes quando disponíveis;
- status ativo/inativo.

## Medidas caseiras
Exemplos:
- xícara 80 ml;
- xícara 200 ml;
- colher de sopa;
- colher de chá;
- unidade média;
- fatia;
- concha;
- copo.

Cada medida deve poder armazenar:
- valor numérico;
- unidade base gramas/ml;
- descrição legível ao paciente;
- ordem de exibição.

## Dieta por refeição
Cada plano alimentar deve possuir refeições ordenadas, como:
- café da manhã;
- desjejum;
- almoço;
- lanche;
- colação;
- jantar;
- ceia.

Cada refeição pode conter:
- item do catálogo;
- item em texto livre;
- quantidade e unidade;
- equivalência em g/ml quando aplicável;
- modo de preparo;
- substituições;
- observações.
