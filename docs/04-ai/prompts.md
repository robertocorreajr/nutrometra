# Prompts-base para Claude Code

## 1. Criar backend de módulo
"Leia `CLAUDE.md` e os documentos de arquitetura. Implemente o módulo em Go separando domínio, aplicação, adapters e delivery. Inclua migrations, handlers, testes e auditoria."

## 2. Criar tela mobile-first
"Leia `CLAUDE.md` e os documentos de frontend. Implemente a tela priorizando celular, estados de erro/loading e feature gating no frontend e backend."

## 3. Criar fluxo clínico
"Considere que o produto atende nutricionistas e pacientes. Implemente o fluxo completo com prontuário, bioimpedância, dieta versionada, publicação ao paciente e exportação assíncrona de PDF."

## 4. Revisar segurança
"Revise este módulo quanto a autenticação, tenant isolation, RBAC, auditoria, rate limiting, vazamento de dados e idempotência."
